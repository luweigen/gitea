# 测试用真实录像

三段 FLIR A655sc 航拍热成像序列，2023-10-21 摄于芬兰约恩苏（Joensuu），由录像所有者
提供用于本扩展的回归测试。文件名里的时间戳就是 [`../truth.mjs`](../truth.mjs) 的索引键。

| 文件 | 帧数 | 首帧数据范围 |
| --- | --- | --- |
| `joensuu2023-10-21T184315890.seq` | 6 | −40.2 … 16.5 °C |
| `joensuu2023-10-21T185820659.seq` | 3 | −31.4 … 9.7 °C |
| `joensuu2023-10-21T190131749.seq` | 4 | −17.3 … 5.3 °C |

三段都是 640×480、未压缩 16 位原始计数（像素值类型 1），相机参数一致：ε=0.95、距离 1 m、
反射表观温度 20 °C、相对湿度 50%、`estAtmosphericTransmission = 0`（即由查看器估算），
记录的显示温标同为 `RawValueMedian ± RawValueRange/2 = 9734 ± 262`。

放在仓库里是为了让测试开箱即跑——`truth.mjs` 里那些 FLIR Thermal Studio 2.0.84 的读数
是本项目唯一不源自同一次逆向的参照，只有配上录像本身才能真正跑起来。代价是约 5 MiB 的
仓库体积（7.65 MiB 原始数据，git 压缩后约 5 MiB）。

第三段（`T184315890`）的动态范围特别大，正好用来检验色标钳位：文件记录的 4.9 K 窗口只
覆盖了它 56 K 跨度的 9%。
